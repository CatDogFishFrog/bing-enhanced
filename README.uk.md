# Bing Enhanced

**Bing Enhanced** — userscript для Tampermonkey, який прибирає проміжні сторінки Bing під час переходу за результатами пошуку, відкриває відео одразу на YouTube чи TikTok і додає кілька зручних налаштувань навігації.

[English version](README.md)

---

## Користувачам

Всі функції можна ввімкнути або вимкнути за бажанням.

### Функції

- Посилання на YouTube у результатах пошуку Bing і розділі «Відео» ведуть одразу на YouTube.
- Посилання на короткі відео TikTok у розділі Bing «Відео» ведуть одразу на TikTok.
- Після натискання на результат пошуку Bing одразу відкривається потрібний сайт, без проміжної сторінки Bing.
- Перехід з основної вкладки загального пошуку до вкладок «Відео», «Зображення», «Карти», «Новини» та «Рейси» відкриває відповідний розділ у поточній вкладці, а не в новому вікні.
- Окремі налаштування визначають, чи відкривати звичайні результати пошуку, відео та новини в поточній або новій вкладці. Типово зберігається поведінка Bing із новою вкладкою.

### Встановлення

1. Встановіть [Tampermonkey](https://www.tampermonkey.net/) у Chrome або Edge. Наразі скрипт перевірявся саме в цих браузерах.
2. [Встановіть Bing Enhanced з останнього GitHub Release](https://github.com/CatDogFishFrog/bing-enhanced/releases/latest/download/bing-enhanced.user.js) і підтвердьте встановлення в Tampermonkey.
3. Відкрийте сторінку пошуку, відео, зображень або новин Bing. Кнопка налаштувань розташована біля поля пошуку.

## Розробникам

Потрібен Node.js версії **22.12 або новішої**.

```sh
npm ci
npm run check
npm run build
```

Готовий userscript створюється у `dist/bing-enhanced.user.js`.

```text
src/
  core/       Ядро
  features/   Незалежні модулі покращення Bing
  locales/    Файли локалізацій
tools/        Окремі інструменти розробки, не входять до збірки userscript
```

Модулі реєструються у `src/features/index.js`; помилка запуску одного модуля не повинна зупиняти інші. Шестерня налаштувань з’являється біля пошукової форми Bing на сторінках пошуку, відео, зображень і новин.

Контракт модуля, схеми налаштувань, порядок fallback-методів і вимоги до очищення описані в [інструкції для авторів модулів](docs/feature-modules.md). Спостерігачі за DOM варто обмежувати потрібною частиною сторінки.

Інтерфейс налаштувань доступний англійською та українською. Інструкція, як додати нову мову одним файлом локалізації: [Локалізація](docs/localization.md). Перемикач debug у меню Tampermonkey показує поточний стан; у debug-режимі виводяться докладні трасування в консолі.

Окремий [збирач діагностики сторінки Bing](tools/bing-environment-recorder.user.js) встановлюється незалежно та не потрапляє до основного userscript. Сценарії запису, структура звіту, застереження щодо приватності й приклади парсингу описані в [інструкції зі збирача Bing Environment Recorder](docs/bing-environment-recorder.md).
