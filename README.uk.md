# Bing Enhanced

**Bing Enhanced** — userscript для Tampermonkey, який покращує щоденне користування Bing: прибирає багато набридливих речей і загалом робить користувацький досвід кращим. Опис конкретних функцій знайдете нижче.

[English version](README.md)

---

## Користувачам

### Реалізовано

- Відео з результатів пошуку або вкладки «Відео» відкриваються одразу на YouTube, як це й мало б бути! Скрипт не робить редирект, а підмінює самі посилання, роблячи їх правильними, що дає моментальне відкриття відео.
- Короткі відео TikTok також відкриваються на сайті TikTok: також підміна посилань, а не редирект.
- Переходи з результатів пошуку на вкладки «Відео», «Зображення», «Карти», «Новини» та «Рейси» відкриваються в поточному вікні.
- Прямі посилання на результати пошуку, а також всі інші внутрішні посилання сайту, замість перенаправлень через проміжні помилання для аналітики. Тепер всі переходи моментальні, без підвантажень аналітики!

### У планах

- Додати перемикач, який визначатиме, чи відкривати посилання в новому або поточному вікні. За замовчуванням Bing завжди відкриває їх у новому вікні.
- Покращити відкриття зображень у вкладці «Зображення». Зараз усе зроблено неймовірно незручно: саме зображення займає мізерну частину екрана, його неможливо розгледіти, а навігація жахлива...
- Можливо, щось зробити з Rewards.
- Можливо, змінити стиль видачі результатів пошуку, зібравши найкраще з різних пошукових систем.

### Встановлення

1. Встановіть [Tampermonkey](https://www.tampermonkey.net/) у Chrome або Edge.
2. [Натисніть тут, щоб встановити userscript](https://github.com/CatDogFishFrog/bing-enhanced/releases/latest/download/bing-enhanced.user.js), і підтвердьте встановлення.
3. Готово. На сторінці пошуку Bing праворуч від поля пошуку з’явиться кнопка налаштувань. Там можна вмикати й вимикати функції.

## Розробникам

Потрібен Node.js версії **22.12 або новішої**.

```sh
npm ci
npm run check
npm run build
```

Готовий userscript створюється у `dist/bing-enhanced.user.js`.

```text
src/
  core/       Ядро
  features/   Незалежні модулі покращення Bing
  locales/    Файли локалізацій
tools/        Окремі інструменти розробки, не входять до збірки userscript
```

Модулі реєструються у `src/features/index.js`; помилка запуску одного модуля не повинна зупиняти інші. Шестерня налаштувань з’являється біля пошукової форми Bing на сторінках пошуку, відео, зображень і новин.

Контракт модуля, схеми налаштувань, порядок fallback-методів і вимоги до очищення описані в [інструкції для авторів модулів](docs/feature-modules.md). Спостерігачі за DOM варто обмежувати потрібною частиною сторінки.

Інтерфейс налаштувань доступний англійською та українською. Інструкція, як додати нову мову одним файлом локалізації: [Локалізація](docs/localization.md). Перемикач debug у меню Tampermonkey показує поточний стан; у debug-режимі виводяться докладні трасування в консолі.

Окремий [збирач діагностики сторінки Bing](tools/bing-environment-recorder.user.js) встановлюється незалежно та не потрапляє до основного userscript. Сценарії запису, структура звіту, застереження щодо приватності й приклади парсингу описані в [інструкції зі збирача Bing Environment Recorder](docs/bing-environment-recorder.md).
